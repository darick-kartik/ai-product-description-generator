# AI Product Description Generator 🚀

A modern SaaS-style AI frontend application that generates high-quality product descriptions for eCommerce platforms.

Built using React + Tailwind CSS + Framer Motion.

---

## ✨ Features

### 🧠 AI Generator
- Product input form
- Brand & category selection
- Tone, language & length options
- Instant description generation UI

### 📊 Dashboard
- Analytics cards
- Charts & stats
- Recent activity

### 📁 Templates
- Prebuilt product templates
- Quick selection system

### 📜 History
- Stores generated results
- Local storage support

### 🔐 Auth UI
- Login / Signup pages
- Social login UI

---

## 🧱 Tech Stack

- React (Vite)
- Tailwind CSS
- Framer Motion
- React Router DOM
- Lucide React
- Recharts
