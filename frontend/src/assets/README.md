# Assets

This directory contains all static assets used throughout the project.

Recommended structure:

```text
assets/
│
├── images/
│   ├── hero/
│   ├── dashboard/
│   ├── logos/
│   ├── pricing/
│   └── testimonials/
│
├── icons/
│
├── illustrations/
│
└── fonts/
```

Currently, the UI uses:
- Tailwind CSS
- Lucide React icons
- Framer Motion animations
- CSS gradients and glassmorphism

No image assets are required at this stage.

Images, SVGs, logos, and illustrations can be added here later without changing the project structure.
